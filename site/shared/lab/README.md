# MATERIAL LAB — как устроена и как расширять

Страница `/lab/` (пока `noindex`, без ссылки в меню). Исходники: `site/shared/lab/*`, страница `site/pages/lab.mjs`, точка входа `site/js/pages/lab.mjs`, стили `site/css/pages/lab.css`.

## Данные: второго каталога нет
- Витрина (8 материалов) — только список артикулов и ручные поправки блеска в `materials.mjs`. Название, фото, цена и ссылка берутся из каталога сайта при сборке страницы.
- Весь каталог лаборатория читает в браузере из существующих `data/catalog.json` (товары) и `data/picker.json` (признаки внешнего вида для фильтров цвета и фактуры). Тест `tests/lab.test.mjs` следит, чтобы артикулы не размножались по коду.
- Поиск (`catalog.mjs → search`) идёт по всем 1202 позициям: артикул (целиком или началом), название, коллекция, формат; ё/е и русская/латинская «х» равны. Позиции без пригодного фото показываются, но помечены «Нет в лаборатории» и ведут на карточку товара.

## Какие изделия попадают в лабораторию (автоматически)
`catalog.mjs → labAsset(product)`:
- плитка с фото и форматом `ШxВ` — да; мозаика, декор, вставки, упаковка — нет;
- меньшая сторона фото ≥ 700 px (`HD_MIN_SIDE`) — **полная симуляция**: цвет с фото, рельеф по светлоте снимка, зерно, тени рельефа;
- меньше — **упрощённый режим**: показывается только то, что есть на снимке; рельеф и зерно не дорисовываются, фото загружается в родном размере (без увеличения), приближение ограничено (`maxPpcm`).
Новая коллекция или новое, более качественное фото в каталоге подхватываются без правок кода: изменится только `catalog.json`. Чтобы выделить материал на стартовом экране, добавьте артикул в `FEATURED` (`materials.mjs`).

## Фильтры
Коллекция и формат — из каталога. Цвет (7 семейств) и фактура (мрамор, камень, бетон, дерево…) — из признаков подбора (`picker-text.mjs → attributesOf`, `catalog.mjs → classify`). Если `picker.json` недоступен, эти два фильтра отключаются, остальное работает.

## Рендер
`gl.mjs` — WebGL 2: две «ячейки» материалов (родное разрешение, до 1024 px на сильных уровнях и 512 px на слабых), GGX, тени рельефа, режим «Сутки» (комната с окном и аналитической тенью проёма), шторка перехода. `canvas2d.mjs` — запасной вид без WebGL 2. `perf.mjs` — уровни качества и адаптация по времени кадра («Авто / Качество / Лайт»). Свет — **художественная модель**, а не физически точное измерение; об этом сказано в интерфейсе.

## Сутки
`timeofday.mjs` — чистые функции от часа (0–24): направление и цвет солнца или луны, свет неба, лампа, свечение окна, экспозиция. Окно и стена заданы в `WORLD`.

## Ссылка на композицию
`composition.mjs` — состояние в строку `#m=…&b=…&l=…&h=…` и обратно. Ссылка открывает лабораторию в том же состоянии.

## Тесты
`npm test` (модульные, включая `tests/lab.test.mjs`) и `npm run test:lab` (браузер: Chromium с программным WebGL 2, настольный и мобильный экран, касания, каталог, сутки, экспорт).
