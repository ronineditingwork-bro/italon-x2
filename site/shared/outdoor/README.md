# X2 Outdoor Lab (`/outdoor/`)

Визуализатор уличных покрытий Italon X2: готовые сцены (дом с бассейном, сруб, фахверк с кострищем) и режим **«Мой участок»** — примерка плитки на фото посетителя.
MATERIAL LAB (`/lab/`, интерьеры и слэбы) — отдельный продукт, общего кода с ним почти нет (используется только разбор формата и каталог).

## Как это устроено

Поверхность (земля, терраса, стена) описывается **гомографией** `H`: пиксель фото → метры на плоскости (`geometry.mjs`). Рисунок плитки считается шейдером в этих метрах,
поэтому перспектива и реальный масштаб получаются сами. Свет и тени берутся из самого снимка: размытое фото делится на средний цвет исходной поверхности (`engine.mjs`).

| Модуль | Что делает |
|---|---|
| `geometry.mjs` | гомография по 4 точкам, камера (горизонт, поворот, поле зрения, высота) → плоскость, масштаб по известному расстоянию, площадь маски. Чистые функции |
| `options.mjs` | монтаж, раскладка, направление, швы и **правила сочетаний** (что нельзя выбрать и почему) |
| `materials.mjs` | материалы X2 из каталога: один цвет — один материал, форматы только из каталога; подстановка оригиналов текстур; расчёт упаковок |
| `mask.mjs` | маски зон: контур с вырезами, мягкий край, уточнение по цвету (убирает траву, воду, мебель), ручные исключения; до 4 зон на кадр |
| `engine.mjs` | WebGL 2: фото + по проходу на зону; швы (затирка, трава, гравий, открытый шов на опорах), «пошаговая» раскладка, сравнение через scissor, снимок |
| `scenes.mjs` | сцены: картинка, камера, зоны-контуры |
| `state.mjs` | ссылка на композицию (`#s=…&t.<зона>=<артикул>.<монтаж>.<раскладка>.<направление>.<шов>`), только обезличенные параметры |
| `app.mjs` | страница: настройки, зоны, расчёт, корзина, JPG, спецификация, жесты |
| `plot.mjs` | «Мой участок»: загрузка фото, контуры, исключения, перспектива, масштаб, черновик |

## Правила и честность
* Форматы и артикулы — только из каталога (`src/catalog.mjs`). Нет 80×80 и 120×264, нет «павлиньего хвоста» и «блокса» (они не раскладываются как плита).
* Недоступные сочетания блокируются с объяснением: на траву — только дорожка/патио, травяной шов — только на траве, «пошаговая» — только дорожка/патио на траве или гравии.
* **Площадь не выдумывается.** На готовой сцене она условная (пользователь вводит свою). На своём фото площадь считается только после того, как задан масштаб (размеры четырёхугольника или известное расстояние).
* Фото посетителя обрабатывается **только в браузере** и никуда не отправляется. Черновик лежит в IndexedDB этого браузера.
* Визуализация приблизительна: цвет зависит от экрана и освещения, масштаб — от точности исходных данных.

## Как добавить сцену
1. Положите картинку **без плитки** (ровное нейтральное основание на будущих покрытиях) в `public/media/outdoor/<id>.webp` и миниатюру 480×320 `<id>-thumb.webp`.
2. Добавьте объект в `scenes.mjs`: `camera` (fov, горизонт в пикселях, поворот, высота камеры), `zones` (контуры; первый контур — внешний, остальные — вырезы).
3. Проверьте вид: `node scripts/build-site.mjs && node tests/outdoor-e2e.cjs`.

Исходные картинки сейчас вырезаны из общего макета скриптом `scripts/outdoor/prep-scenes.py` (убирает подписи и выноски). Для лучшего качества замените их чистыми рендерами в большем разрешении.

## Текстуры плиток
Каталожные фото X2 — 171×341 / 341×341 px. Если для артикула подключён оригинал (`data/lab-originals.json`, см. `scripts/lab-originals.mjs`), Outdoor Lab берёт его
(на телефоне — уменьшенную копию `mobile`) автоматически.

## Тесты
`npm test` (модульные: `tests/outdoor.test.mjs`) и `node tests/outdoor-e2e.cjs` (браузер, десктоп и телефон; нужна `npm run build:site`).
