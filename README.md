# Italon Experience — italon-x2.ru

Сайт фирменного салона Italon Experience в Краснодаре. Отдельный проект для домена **italon-x2.ru**.

## Возможности

- Каталог 993 товаров: 928 Italon и 65 X2, поиск по названию и артикулу, фильтры коллекций и форматов.
- Фотографии 992 товаров, интерьерные и уличные фотографии 42 коллекций, четыре способа укладки X2.
- Примеры террасы, садовых дорожек и зоны у бассейна с переходом к соответствующим материалам.
- Расчёт количества упаковок и минимального заказа, корзина с сохранением на сервере.
- Коммерческое предложение в PDF с кириллицей, реквизитами товара и итогами. PDF формируется в браузере.
- Контакты салона: Краснодар, ул. Бабушкина, 248; +7 918 24 89 248; italon@amanagroup.org.

Цены взяты из прайса на 1 июля 2026 года для Краснодара, с НДС. Раздел Coliseum предназначен для будущего ассортимента. Сайт не принимает оплату и не отправляет заказы автоматически.

## Локальный запуск

Нужны **Node.js 24**, npm и Git. Сборка записывает идентификатор текущего коммита, поэтому исходники нужно запускать из Git-репозитория.

```bash
npm ci
npm run dev
```

Открыть http://localhost:4174 . Сервер использует отдельную SQLite-базу в `.hosting-runtime/dev/`, которая сохраняется между запусками. После изменений исходников перезапустить команду.

```bash
npm run dev -- --port 4175 --host 127.0.0.1
```

## Сборка для сервера

```bash
npm run build
```

Готовый комплект появится в `.hosting-runtime/release/`: `public/`, `server/`, SQL-миграции, Dockerfile, Docker Compose, Caddy и инструкция `TRANSFER.md`. Выполнять команды Docker Compose из этого каталога. Скопировать `.env.example` в `.env` и заполнить домен и контакт для сертификата.

Подробная инструкция: [hosting/TRANSFER.md](hosting/TRANSFER.md). Для запуска нужен сервер с Docker Compose либо Node.js 24 и HTTPS-прокси. Постоянная SQLite-база хранится отдельно от кода и образа приложения. GitHub используется для исходников; публикация репозитория сама по себе не переключает хостинг и DNS домена.

Снимки корзин, рабочие базы, резервные копии и секреты не хранятся в репозитории. Перенос корзин выполняется отдельно через `server/import-carts.mjs` в готовой сборке.

## Проверки

```bash
npm run check
npm test
npm run test:hosting
node tests/ui-check.mjs
```

Проверяются упаковки, минимальные партии, расчёт цен на сервере, сохранение корзин после перезапуска, изоляция посетителей, конфликт версий, фотографии и скачивание PDF. Запуск Docker/Caddy и выпуск публичного TLS-сертификата требуют проверки на выбранном сервере.

## Структура

| Каталог | Содержание |
| --- | --- |
| `public/` | HTML, стили, локальные фотографии и шрифты |
| `src/` | Интерфейс, каталог, галереи и PDF |
| `data/` | Прайс и происхождение изображений |
| `worker/` | Общая логика API и корзины, используемая сервером Node.js |
| `hosting/` | Сервер Node.js, SQLite, Docker Compose и Caddy |
| `drizzle/`, `db/` | Версионированная схема базы |
| `scripts/` | Сборка, локальный запуск и импорт материалов |
| `tests/` | Проверки каталога, корзины, сервера и интерфейса |

Фото и описания относятся к представленным материалам; данные об остатках не предполагаются. Источники изображений сохранены в `data/image-provenance.json` и `data/context-image-provenance.json`. Лицензии шрифтов находятся в `public/fonts/`.
