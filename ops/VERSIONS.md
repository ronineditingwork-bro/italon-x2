## Как вернуться к версии N

Откат — новым коммитом, история не стирается (потом можно вернуться и вперёд):

```bash
git fetch origin
git checkout ccr-943f3ebb-rcco8n
git pull origin ccr-943f3ebb-rcco8n
git checkout versions/vN -- .
git commit -m "Откат сайта к версии vN"
git push origin ccr-943f3ebb-rcco8n
```

Через 5–10 минут сервер соберёт сайт. Корзины клиентов и сертификаты при этом не трогаются.
