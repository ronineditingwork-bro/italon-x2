# Outdoor Lab — новые дома (этап 24.10.2026)

Готовы две новые фотореалистичные исходные сцены **без плитки**:
- `red-brick.webp` — небольшой одноэтажный дом из красного кирпича, тёмные окна RAL 7024, забор «расчёска». Терраса и дорожка.
- `white-country.webp` — белый двухэтажный американский кантри, чёрные рамы, крытая веранда. Терраса и дорожка.

Две сцены описаны в `site/shared/outdoor/scenes.mjs`, содержат приблизительную камеру и ручные контуры без обязательного точного геодезического масштаба. Подложки нельзя заменять уже покрытыми плиткой фотографиями: это даёт двойные швы и 3D-артефакты.

## **Важно: не публиковать эту ветку до установки медиафайлов**

Четыре файла, подготовленные вне GitHub и упакованные в `outdoor-scene-pack.zip`, нужно разместить в `public/media/outdoor/`:
- `red-brick.webp`, `red-brick-thumb.webp`
- `white-country.webp`, `white-country-thumb.webp`

В архив входят диагностические изображения `*-zones.jpg` с подсветкой двух зон, `manifest.json` и исходные WebP.

Для установки на компьютере, где доступен ZIP из чата, используйте команду ниже в корне репозитория. Скрипт работает в Node.js без сторонних библиотек, проверяет SHA-256 каждого WebP и записывает **только** четыре изображения:

```sh
node scripts/outdoor/import-scene-pack.mjs /путь/к/outdoor-scene-pack.zip
```

Можно сначала проверить архив без изменений: добавить `--dry-run`.

После установки выполнить:

```sh
node scripts/outdoor/verify-scene-assets.mjs
npm run check
npm test
npm run build
npm run test:hosting
npm run test:outdoor
```

Камеры откалиброваны ориентировочно под крупный загородный кадр (линии горизонта 335 и 345 px, высота камеры 1,5 м): плитка не должна превращаться в микротекстуру у порога. Проверять на настоящем браузерном WebGL перед релизом.\n\nКонтур красного кирпичного дома уточнён вручную для полного покрытия террасы, без захвата переднего газона. Контуры проверены визуально на полном исходном кадре 1536 × 1024. Поскольку земля у готовых сцен калибруется приблизительно, все рассчитанные площади в интерфейсе должны маркироваться как оценочные до ввода пользователем своего размера.

## Шестая сцена

**Индустриальный дом** с бетоном, кортеном и обожжённым чёрным деревом ещё **не включён**. Прежние генерации содержали интерфейс или заранее нанесённую плитку, поэтому не подходят для WebGL-маски. Не подменять её чужой архитектурой или низким разрешением. Нужен чистый кадр 1536 × 1024 или больше, без мебели, со свободной террасой/дорожкой, после чего разметить зоны.

## Публикация

Сервер `hosting/auto-update.sh` может самостоятельно выложить коммит из `ccr-943f3ebb-rcco8n`. Поэтому новые сцены ссылаются только на локальные WebP, а этот PR нельзя сливать без всех четырёх файлов, положительных проверок и реального smoke-test после релиза. `main` не трогать.
