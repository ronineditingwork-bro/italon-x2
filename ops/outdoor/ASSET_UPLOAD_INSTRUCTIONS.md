# Outdoor Lab — передача утверждённых изображений в Claude

Эта ветка **только для передачи медиа**. Она создана от `ccr-943f3ebb-rcco8n`. Ветка боевого сайта не изменена.

## Ожидаемые файлы в `public/media/outdoor/`

- `red-brick.webp` — 1536 × 1024
- `red-brick-thumb.webp` — 480 × 320
- `white-country.webp` — 1536 × 1024
- `white-country-thumb.webp` — 480 × 320
- `industrial.webp` — 1536 × 1024, предварительная подложка
- `industrial-thumb.webp` — 480 × 320
- `industrial-approved.png` — 1536 × 1024, утверждённый исходный кадр; **не заменять на другое изображение**

Файлы должны быть загружены в GitHub в **открытую ветку `assets/outdoor-pack`**, а не в `main` или `ccr-943f3ebb-rcco8n`. Архив .zip в репозиторий не загружать: загрузить именно распакованные изображения.

После появления файлов Claude должен сделать `git fetch origin assets/outdoor-pack` и получить изображения из ветки, закончить третью сцену, уточнить маски и проверить дизайн без переделки существующей страницы. Код сцены №4/№5 есть в PR #6.

`industrial.webp` пока является только предварительной подложкой — исходник для окончательной очистки бетонных швов хранится в `industrial-approved.png`. Нельзя считать индустриальную сцену окончательно готовой до реальной проверки наложения текстур.

После скачивания файлов проверьте, что все семь файлов присутствуют и открываются, затем запускайте тесты сборки. Не сливайте в боевую ветку без их прохождения.

См. текущий PR: https://github.com/ronineditingwork-bro/italon-x2/pull/6
