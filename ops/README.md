# ops/ — эксплуатация сайта italon-x2.ru (этап 1: защита рабочего сайта)

Здесь лежит всё, что относится не к страницам сайта, а к его безопасной жизни: выкладка проверенных версий, откат, резервные копии заявок, персональные данные.

> **Важно: всё это подготовлено в отдельной ветке `stage1/safe-release` и пока НЕ включено.** Ветка `ccr-943f3ebb-rcco8n`, которую сейчас каждые 5 минут забирает сервер, и сам сервер не изменялись. Прежнее автообновление продолжает работать, пока вы сами не переключитесь по инструкции.

Файлы-«рельсы»:

- `ops/catalog-baseline.json` — эталон каталога (1202 артикула, 75 коллекций). CI не даст выложить версию, в которой что-то из этого пропало. Обновляется осознанно: `node scripts/verify-catalog.mjs --update-baseline` (например, после загрузки нового прайса).
- `ops/legacy-deploy.sha256` — отпечатки `hosting/auto-update.sh` и `hosting/deploy-reg-ru.sh`. Эти два файла управляют боевым сервером через прежнее автообновление, поэтому тест `tests/ci-config.test.mjs` падает, если их изменили случайно.
