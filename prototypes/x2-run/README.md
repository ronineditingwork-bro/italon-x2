# X2 / ГОРОД — 2D-игра в духе Contra

Бегалка-стрелялка с боковым видом и современной векторной графикой (без пикселей). Робот X2 с коробкой плит бежит по кварталу, стреляет плитами по «браку» — треснувшему покрытию, дронам-осколкам, люкам-турелям и ржавой технике — и **укладывает за собой новую мраморную плитку**. Четыре зоны (парковка, подъезд к дому, тротуар, территория у бассейна) и четыре босса: асфальтоукладчик, бетономешалка, дорожный каток, экскаватор.

**Подключена к сайту** (страница `/x2/game/`, `site/pages/x2-game.mjs`): движок собирается esbuild из этой папки и грузится только по кнопке «Играть» (`site/js/pages/x2-game.mjs`). В образ сервера попадает готовая сборка из `public/assets/`, а не эта папка. Предыдущая 3D-версия лежит в `prototypes/x2-game` и больше не используется.

## Запуск

```
cd prototypes/x2-run
python3 -m http.server 4192        # любой статический сервер
# открыть http://127.0.0.1:4192/index.html  (с ?test=1 доступен window.__X2__ для проверок)
node --test tests/game.test.mjs    # правила игры (без браузера)
node tests/e2e.cjs                 # управление, пауза, конец игры, экранные кнопки (Playwright + Chromium)
```

Сборки нет: ES-модули подключаются напрямую, внешних библиотек и картинок нет — графика и звук рисуются и синтезируются кодом.

## Управление

| Что | Компьютер | Телефон |
|---|---|---|
| Бег | ← → или A D | кнопки ◀ ▶ |
| Прицел вверх / пригнуться | ↑ / ↓ | ▲ |
| Прыжок | Пробел, Z или K (короткое нажатие — прыжок ниже) | «Прыжок» |
| Огонь | X, J или Shift (держите — очередь) | «Огонь» |
| Спрыгнуть с уступа | ↓ + прыжок | — |
| Пауза | Esc или P | кнопка ❚❚ |

Работает и геймпад (стандартная раскладка: крестик/стик, A — прыжок, X/B/RT — огонь, Start — пауза). Прицел — 8 направлений, как в Contra.

## Правила

- 5 сердец (максимум 7). Попадание или падение в яму — минус сердце, затем 2,2 с неуязвимости, оружие сбрасывается. В начале каждой зоны +1 сердце, в каждой зоне есть дрон с сердцем.
- Дроны с коробками X2: стреляйте по ним — выпадает **Веер** (3 плиты), **Скорострел**, **Тяжёлая плита** (урон ×4, прошивает врагов), **Щит** (7 с) или **Сердце**.
- «Брак»: бегун-плитка (1 попадание), дрон-осколок (2, стреляет), люк-турель (5, уязвима только пока открыта), каток (8, таранит).
- Ямы: траншеи (в зоне у бассейна — с водой) не шире 175 px, а прыжок уносит вперёд примерно на 235 px; есть и запас по времени на прыжок после схода с края («койот»).
- Укладка: каждые 96 px пути позади робота ложится ряд из 6 плит по 0,36 м² (2,16 м²), за уничтоженный дефект добавляется плитка-другая, за босса — 18 м². Площадь условная и к расчёту заказа не относится.
- Рекорд хранится в `localStorage` браузера.

## Структура

```
index.html            отдельная страница для запуска и проверок
src/config.js         все числа: скорость, оружие, враги, босс, зоны, укладка
src/level.js          уровень из seed: ямы, уступы, враги, дроны, арены боссов
src/game.js           правила и физика без графики (шаг 1/60 с), события для графики и звука
src/render.js         отрисовка кадра, частицы, тряска, вспышки, вылет плит
src/art/*.js          робот, враги и боссы, фон и спрайты, дорожка и плитка — всё рисуется кодом
src/ui.js, styles.js  HUD, меню, пауза, итоги, экранные кнопки (классы x2r-*, не пересекаются со стилями сайта)
src/input.js          клавиатура, экранные кнопки, геймпад
src/audio.js          звуки и музыка синтезируются WebAudio, выключаются кнопкой
src/main.js           mountGame(root) → { game, advance, setQuality, destroy }
tests/                game.test.mjs — правила; e2e.cjs — браузер; *-sheet.html — листы поз и врагов для художника
```

## Качество и скорость

- «Высокое» (по умолчанию на ПК): плотность 2×, мягкие свечения, больше частиц. «Лёгкое» (телефоны, слабые CPU): плотность до 1,25×, без свечений, меньше частиц. Если на высоком кадры дольше 2,5 с идут медленнее ~28 к/с, игра сама переходит на лёгкое.
- В проверочном окружении (программный рендер без GPU) игра держит 40–50 к/с; на реальных телефонах не измерялась.

## Ограничения

- Баланс сложности проверен ботом (боссы убиваются за 10–40 с, весь забег ≈ 2,5–3 мин), живых игроков ещё не было: числа в `config.js` стоит подкручивать по отзывам.
- Графика векторная и процедурная: персонажи нарисованы кодом и ближе к иллюстрации, чем к 3D-рендеру концепта. Для анимации «как в мультфильме» понадобятся спрайты от художника.
- В портретной ориентации играть можно, но мелко: игра подсказывает повернуть телефон.
