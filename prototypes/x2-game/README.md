# X2 / ГОРОД — прототип мини-игры

Отдельный интерактивный прототип для будущего добавления на сайт Italon X2. Маленький робот X2 с коробкой на спине бежит по кварталу и меняет старое покрытие на утолщённый керамогранит X2. **К действующему сайту не подключён, на сайте не публикуется**: папка лежит вне `public/` и в образ сервера не попадает.

## Запуск

```bash
cd prototypes/x2-game
python3 -m http.server 4190 --bind 127.0.0.1      # любой статический сервер
# открыть http://127.0.0.1:4190/index.html
```

Сборка не нужна: ES-модули и Three.js (`vendor/`) подключаются напрямую. Адрес с `?test=1` открывает `window.__X2__` для автоматических проверок.

## Управление

| | |
|---|---|
| Компьютер | ← → (или A, D) — полоса · Пробел (↑, W) — прыжок · Esc (P) — пауза |
| Телефон | свайп влево/вправо — полоса · свайп вверх — прыжок · экранные кнопки (включаются в меню и по умолчанию на сенсорных экранах) |

## Правила (значения вынесены в `src/config.js`)

- Забег — 60 секунд, по 15 секунд на зону: парковка → подъезд к дому → тротуар → территория у бассейна.
- Автоматический бег, три полосы (по две плитки в каждой).
- Коробки X2 — широкая укладка на все три полосы на 4 секунды.
- Низкие препятствия (конус, ограждение) можно перепрыгнуть; вазоны — только объехать.
- Три столкновения завершают забег; после удара — защита 1,6 с, чтобы одно препятствие не отнимало несколько попыток.
- Счёт — только за впервые заменённые плитки, 0,36 м² за плитку (условная система счёта, не коммерческий расчёт).
- Названия заменяемых покрытий (список — `CONFIG.brands.replacementBrands`) лежат на участках маршрута и исчезают после замены.

## Устройство

```
index.html            страница-оболочка (монтирует mountGame)
src/config.js         все настройки: темп, правила, зоны, бренды, качество, камера
src/rng.js            детерминированный генератор (seed в конфиге)
src/track.js          маршрут: участки с брендами, препятствия, коробки (без графики)
src/game.js           состояние и правила: step(dt), moveLane, jump, pause… (без графики)
src/input.js          клавиатура, свайпы, экранные кнопки
src/ui.js, styles.js  интерфейс на русском, внедряется модулем
src/main.js           mountGame(root) → { game, stage, advance, destroy }
src/render/stage.js   сцена Three.js: камера, свет, мир, робот, эффекты, освобождение ресурсов
src/render/robot.js   робот из геометрии и анимация бега/прыжка
src/render/world.js   плитки (instancing), бренды на покрытии, препятствия, коробки
src/render/decor.js   декорации четырёх зон (одна склейка геометрий)
src/render/fx.js      летящие плиты и частицы (пулы)
src/render/textures.js  все текстуры рисуются на canvas, внешних картинок нет
vendor/               Three.js 0.160.0 (см. vendor/VERSIONS.md)
tests/                game.test.mjs — правила; e2e.cjs — управление, пауза, концовка в браузере
```

Игра не требует регистрации, не обращается к корзине и ничего никуда не отправляет.

## Проверки

```bash
node --test tests/game.test.mjs      # правила, без браузера
node tests/e2e.cjs                   # нужен запущенный сервер и Chromium с WebGL
```

## Отличия от визуального концепта

- Робот собран из примитивов (скруглённые боксы, цилиндры, сферы), а не из отдельной 3D-модели: силуэт, куб-голова с экраном и голубыми глазами, шарниры, коробка на ремнях с подачей плит сохранены, мелкие детали упрощены. Для точной копии нужна отдельная GLB-модель.
- Графика стилизованная (низкополигональные дома, машины, деревья), а не фотореалистичная.
- Звука нет (кнопка отключения не нужна).
- Плиты при полёте для читаемости слегка утолщены.

## Ограничения

- Производительность проверена только в программном рендерере (SwiftShader), без реальных телефонов. Для слабых устройств есть режим «Сниженное качество» (без теней, меньше декораций и частиц); при выборе «Авто» он включается на сенсорных экранах и слабых CPU.
- Для интеграции на сайт нужны отдельная проверка на реальных устройствах и согласование места на странице.
